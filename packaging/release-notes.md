Elastic UI v1.0.1，修复启动提示和连接反馈。

- 四项防护均为“仅检测”时，不再每次启动自动弹出故障窗口。“防护降级”状态仍会显示，详情入口改为“查看防护详情”，并说明仅检测只记录威胁、不阻止。
- 自动提示只用于连接失败、Agent 或防护不可用、防护模块关闭、运行状态异常等需要处理的情况。
- Elastic 服务未启动或网络不可达时，首屏立即显示连接进度和超时说明，窗口不再长时间停在无反馈的加载状态。
- 托盘、任务栏、程序文件和安装包统一使用 Elastic Defend 图标。
- 首次连接页面不再预填任何 Kibana 地址、Elasticsearch 地址和用户名。
- 保留原有配置、隔离区恢复记录、扫描、信任应用、独立策略、通知和开机自启功能。

推荐下载 `elastic-ui-windows-amd64-setup.exe`；独立程序为 `elastic-ui-windows-amd64.exe`。`SHA256SUMS` 提供文件校验值。

需要 Windows 10 / 11 x64、已注册的 Elastic Agent / Defend，以及 Kibana / Elasticsearch 权限。安装器缺少 WebView2 时从微软下载运行时。当前程序及安装包未配置代码签名证书。

隔离文件保存为加密 ZIP，密码为 `elastic`；不会自动解压到原位置。“已配置信任”表示策略中存在 SHA256 信任应用规则。集中管理与解除主机隔离仍在 Kibana 完成。
